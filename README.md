# Отчет по практическим работам: «Калькулятор» и «Угадайка»

В данном репозитории представлены две практические работы, демонстрирующие навыки адаптивной верстки с использованием фреймворка Bootstrap и реализации интерактивной логики на чистом JavaScript.

---

## 1. Работа «Калькулятор»
Простое веб-приложение для выполнения базовых арифметических расчетов.

**Выполненные требования:**
* Адаптивный интерфейс карточного типа, построенный на сетке Bootstrap.
* Обработка ввода цифр и сброса состояния (кнопка `C`).
* Реализация базовых бинарных операций: сложение (`+`) и вычитание (`-`).
* Хранение промежуточного операнда в памяти и вывод итогового результата в текстовое поле по нажатию кнопки `=`.

---

## 2. Работа Игра «Угадайка»
Интерактивное приложение, в котором программа угадывает загаданное пользователем число методом бинарного поиска.

**Выполненные требования:**
* Реализован случайный выбор фраз для вопросов компьютера и для экрана победы (использован объект `Math.random`).
* Использован оператор дизъюнкции (`||`) для автоматической подстановки значений по умолчанию, если пользователь ввел некорректные данные или текст (`NaN`).
* С помощью компактных тернарных операторов реализовано жесткое ограничение диапазона чисел в рамках от `-999` до `999`.
* Написан алгоритм, разбирающий число на сотни, десятки и единицы, и переводящий его в текстовую форму (словами), включая обработку отрицательных чисел. Если длина получившейся строки меньше 20 символов, число выводится текстом, иначе — цифрами.
* Полностью исключены стандартные браузерные функции `prompt` и `alert`. Настройка игры и сам игровой процесс разнесены по разным блокам, переключение между которыми происходит бесшовно с помощью встроенного класса Bootstrap `.collapse` через управление `classList` в JS.
* В файле `style.css` настроена аккуратная цветовая гамма (пастельный бирюзовый фон, контрастная шапка карточки игры, мягкие тени элементов) для придания приложению уникального внешнего вида.

---

## Технологический стек
* **HTML5** — структурирование страниц.
* **CSS3** — кастомные стили и кастомизация компонентов.
* **Bootstrap 4** — адаптивная сетка, кнопки, элементы форм и класс `.collapse`.
* **JavaScript (ES6)** — работа с DOM, валидация данных, реализация алгоритмов бинарного поиска и конвертации чисел.

## Запуск проектов
Для запуска любого из приложений достаточно открыть соответствующий файл `index.html` в любом современном веб-браузере.
